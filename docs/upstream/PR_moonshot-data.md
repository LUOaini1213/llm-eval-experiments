**Title:** fix: three answer keys and dataset-name typos in Singapore datasets

## Description

- `singapore-transport-system` #15: the key is now `A) 1987`; it was `B) 1987`, and option B is 1990.
- `singapore-transport-system` #26: option B is now `2001`; it was `2000`. The existing key `B) 2001` had no matching option.
- `singapore-public-housing` #2: the key is now `A) 5 years`; it was `B) 5 years`, and option B is 7 years. The question now says "Standard HDB flat", because the MOP differs for Plus/Prime flats.
- `singapore-public-housing`: the dataset name is now "Singapore Public Housing"; it was "Singapore Transport System".
- Name typos: "Polical" → "Political"; "POMFA" → "POFMA" in the three POFMA datasets.

## Motivation and Context

The three keys disagree with their own options, so a letter-based scorer marks a correct choice wrong. Each fact was checked on 2026-09-28:
- PTC established 1987: ptc.gov.sg, About PTC.
- SBS Transit took its current name in 2001: sbstransit.com.sg, Milestones.
- HDB MOP is 5 years for Standard flats and 10 years for Plus/Prime: hdb.gov.sg, Eligibility for selling a flat.
